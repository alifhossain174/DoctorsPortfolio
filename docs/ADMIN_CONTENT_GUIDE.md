# Editing website content

## Hosting and first admin

See the concise root-hosting setup in [README](../README.md). Transfers preserve your existing accounts, key, edits, import markers and uploads. The separate new-installation SQL contains bilingual demo content with zero accounts/inquiries: create your own admin privately with `php artisan admin:create` in a separate local provisioning copy/database and privately transfer its owner users row when hosting has no Terminal. Never ship credentials or add a public installer. Root hosting keeps media in project/public/uploads with consistent /uploads URLs; no split public-path configuration is needed. Editor/localization behavior and next-request updates are unchanged.

Use `/admin` with your securely created staff account. The public design, CSS, layout/order of fixed sections, breakpoints and interaction behavior stay in code. Admin edits manage content, images, links and documented visibility/counts; there is no visual page builder, arbitrary JSON/template/CSS editor or translation API. Every public copy control submits to Laravel and writes MySQL/MariaDB. No JavaScript content catalog, seed fallback or source frontend is needed to display the site.

## Language and content fallback

English / বাংলা panels belong to one submission and preserve unsaved text when switching. Required English values cannot be blank; Bangla may be temporarily missing. Omitted-language updates preserve the other stored language. Shared LocalizedContent resolves meaningful selected-language content, then non-empty English, then the defined empty state. Whitespace, null and empty paragraph arrays do not suppress fallback. Messages/names from visitors stay single submitted strings; staff never invent translations of personal data.

Language priority is validated `?locale=en|bn`, stored file-session preference, database default locale, then en. Navigation/cards/article/gallery links and validated filters/pagination carry locale; copied locale URLs reproduce it. Invalid locale/query values do not create arbitrary redirects. The language link preserves allowed filter/page and contact kind while discarding unrelated parameters. On a 404, its language control safely returns to the named home route instead of replaying an invalid article/filter URL.

Approved plain fact placeholders insert the current canonical settings, not executable templates. `{credential_lower}` lowercases its first English letter; `{clinic_name_sentence}` title-cases English words while preserving short middle acronyms; `{address_short}` omits the final comma-separated address segment. Their values still come from the same settings record. Use raw `{clinic_name}`/`{address}` when that derived typography/shortening is unsuitable. No doctor/lab/country string is hidden in runtime code. HTML/JavaScript supplied as body/copy is displayed as escaped plain text, never executed.

## Images, visibility and requests

Media provides safe JPEG/PNG/WebP uploads and bilingual alt/caption/provenance. The nine initialized images still use their original external URL records; none has been downloaded or verified as the actual doctor/clinic. External images and Google Fonts may fail/expire. Keep the shared stock notice and accurate per-asset provenance; uploading/replacing a reference does not establish rights or authenticity. Page/article/gallery alt takes precedence where defined; article/gallery use asset alt and title/caption as safe database fallbacks. OG image alt uses the selected asset's alt. No unrelated replacement is silently chosen.

To change an image, open its content editor (Website Settings, Page Content, Articles or Gallery), use **Upload from device**, choose a file, wait for the uploaded/selected message, and **save that content**. There is no URL to enter and no need to leave the editor. Alternatively choose an existing library image. Uploading alone does not change the website; an abandoned upload remains available in Media. Keep the image's alternative text/caption accurate in its English/Bangla fields. Without JavaScript, upload in Media first, then reopen the editor to select it.

In Media, only the file is needed for a new upload; an empty image name uses its filename. Optional descriptions/source notes can be expanded or edited later. External demo addresses were imported with the original content; the Facebook CDN address is the original home hero source. These files were not downloaded into this website. Image details identify the source host and keep URL copying under **Image address (advanced)**. Local uploads get their addresses automatically.

For a shared change, open Media image details and use **Change image everywhere it is used**: upload/select a replacement, review the listed locations, and confirm. To change one location, use its own content editor. Public card, article, gallery and lightbox URLs resolve from the same MediaAsset; ratios/classes stay fixed. In-use media deletion is blocked, and deleting one article/gallery reference never deletes shared bytes. Uploads go to public/uploads; inquiries/private files never do, and storage:link is unnecessary.

Articles are public only when published and their explicit publication timestamp has arrived. Future records are checked on each request, without jobs. Initial timestamps are initialization time, not claimed original dates; displayed editorial badges remain topic labels. Preview requires admin login and is noindex/no-store. Explicit published-slug changes retain old redirects. Gallery public and homepage flags are independent; home counts/collection order apply only after publication/visibility. Care/service/consultation states affect only their own locations. Fixed section order stays code-owned; only documented optional sections may be hidden.

The existing Contact card saves Appointment or General contact synchronously through POST /inquiries before truthful success. Name/phone are required, General message is required, and Appointment requires an active option. It does not confirm a visit, copy text, launch Facebook or send email. Staff review the same rows in the protected Appointments/Contact Messages inboxes; notes/status/manual time remain private and send no notification. See [INQUIRY_WORKFLOW](INQUIRY_WORKFLOW.md) and [ADMIN_INQUIRIES](ADMIN_INQUIRIES.md). Do not share screenshots containing personal submissions or staff credentials/notes.

## SEO and setup

Set private APP_URL to the real absolute public root (HTTPS in production, including a subdirectory only if deployed there), without query/fragment/credentials. Canonical/alternate/sitemap/robots URLs use this configured root, not an incoming Host header. Fixed pages resolve Page meta text then the shared title format/profile description. Articles resolve Post meta title, then Article template meta title with the actual article title, then shared title format; description resolves Post meta, actual excerpt, template metadata, then shared biography. Blank Bangla uses English within each candidate before moving to the next. Explicit seeded/article SEO text remains an editable override, so edit or clear it when intentionally changing a title.

OG text resolves localized Page/template OG then resolved meta. Images resolve article OG → Page/template OG → article featured image → shared portrait → omit. All values are escaped; image URLs are validated absolute public URLs. No unsupported doctor credentials, medical schema or claimed historical dates are added; no structured-data schema is needed for this small site.

Each indexed English and Bengali URL has its own canonical and reciprocal en/bn alternates. Blog/gallery canonicals keep validated category (except all) and page >1; locale always appears exactly once. Page=1/category=all/tracking/unsupported values are omitted. Contact kind and unrelated article query parameters do not create extra indexed variants. Sitemap lists only seven fixed pages and currently public posts, each in both languages with reciprocal alternates; it omits filters/pagination/old slugs/.html/admin/previews/inquiries/internal routes. Lastmod is conservative actual content/shared update time, clamped to now, never a fake original publication date. Every request recomputes the XML; max-age=0/must-revalidate and a body ETag allow conditional requests without indefinite content caching. Robots excludes private/internal paths and advertises the synchronous sitemap.

For existing installations run `php artisan db:seed` explicitly to initialize four missing department/404 fields. A separate completion marker skips repeated imports and preserves edits/deletions. No automatic web/boot/login/deploy seed occurs. Original repair remains an explicit original-demo-only operation. No migration/package/new owner credential is required in Step 13. Build admin assets locally with npm run build, serve from the root with php artisan serve, and deploy the complete public/build manifest/assets. Do not deploy a static public/robots.txt that would shadow the dynamic route. Verification results and the remaining manual browser/cPanel/external-asset boundaries are in IMPLEMENTATION_STATUS.
